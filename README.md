# TecniApp ICE

This repository contains the source for the TecniApp ICE project. The project is built with Gradle and is intended to be opened with Android Studio or IntelliJ IDEA.

The `.idea` folder generated by the IDE is not tracked in version control. If you clone the repository and use Android Studio or IntelliJ IDEA, the IDE will recreate this directory automatically.

To build the project from the command line, run:

```bash
./gradlew build
```
