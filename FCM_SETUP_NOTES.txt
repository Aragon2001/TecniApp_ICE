Resumen rápido para activar el flujo FCM completo:

1) Android listo para recibir FCM
   - Se agregó un servicio FirebaseMessagingService en `com.Arasoftsolutions.tecniapp_ice.fcm.TecniAppMessagingService`.
   - El token FCM se guarda en Realtime Database en `/usuarios/{uid}/fcmToken` cuando hay un usuario autenticado.
   - Cada push con `data.caseId` dispara `AveriaNotificationDispatcher` respetando los filtros de agencias configurados en la app.
   - Si quieres probar manualmente, puedes enviar un mensaje de datos desde la consola FCM con al menos `caseId` y `estado`; opcionalmente `agencia`, `nombreAgencia`, `region`, `descripcion`, `localizacion`, `lat`, `lng`, `clientesAfectados`, `causa`, `nise`, `agenciaTag`.

2) Estructura esperada en Realtime Database
   - Nodo `/usuarios/{uid}/fcmToken` (lo actualiza la app automáticamente).
   - También debería existir por usuario la subregión/agencia que uses para enrutar las notificaciones desde el servidor (por ejemplo `/usuarios/{uid}/subregionId` y `/usuarios/{uid}/agenciaId`).

3) Backend con Firebase Cloud Functions (borrador)
   - Instala CLI: `npm install -g firebase-tools` y luego `firebase login`.
   - Inicializa en una carpeta vacía: `firebase init functions` (elige JS/Node 18+, tu proyecto TecniApp, opcional ESLint).
   - En `functions/index.js` implementa una función programada (ejemplo `syncAveriasYNotificar`) que:
     a) Llama a la API del ICE cada ~5 min.
     b) Detecta averías nuevas o con cambio de estado (guarda snapshot en `averias_last_snapshot`).
     c) Busca tokens en `/usuarios` filtrando por subregión/agencia.
     d) Envía un `sendEachForMulticast` con `notification` y `data` que incluya al menos `caseId`, `estado`, `agencia`, `descripcion`, `region`, etc.
   - Guarda el token del ICE en config: `firebase functions:config:set ice.token="TU_BEARER_TOKEN"`.
   - Despliega: `firebase deploy --only functions`.

4) Validaciones rápidas
   - Verifica en Realtime DB que el usuario logueado tenga `fcmToken` y su subregión/agencia.
   - Observa los logs de Cloud Functions tras cada ejecución programada para confirmar envíos.
   - En el teléfono, aunque la app esté cerrada, deberías ver la notificación.
